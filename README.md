# 📊 Loan Portfolio Analysis Dashboard

## 📌 Overview
This project analyzes loan data to evaluate portfolio performance, track repayments, and identify default risk using Power BI, SQL, and DAX.

## 🛠 Tools Used
- Power BI
- SQL
- DAX
- Excel (CSV)

## 📂 Dataset
- Customers
- Loans
- Payments
- Defaults

## 📊 Key Metrics
- Total Disbursed Amount
- Total Paid Amount
- Outstanding Amount
- Default Rate
- Loan Distribution by State & Type

## 📈 Insights
- Identified high-risk loan segments
- Analyzed repayment trends over time
- Monitored outstanding loan exposure
